## 🛠️ ÉTAPES POUR MODIFIER LES MILESTONES

### Étape 1 : Aller sur GitHub

1. Allez sur **https://github.com/hmirinsalma/syndichub**
2. Cliquez sur l'onglet **Issues**
3. Dans le menu à gauche, cliquez sur **Milestones**

Ou directement : **https://github.com/hmirinsalma/syndichub/milestones**

---

### Étape 2 : Modifier chaque milestone

**Pour CHAQUE milestone** :

1. Cliquez sur le **nom du milestone** (ex : "Phase 0 - Initialisation")
2. Cliquez sur **Edit** (bouton en haut à droite)
3. Dans le champ **Due date**, entrez la date correspondante (format DD/MM/YYYY)
4. Cliquez sur **Save changes**

---

### Étape 3 : Fermer les milestones terminées

Les phases 0, 1, 2, 3 sont **terminées** :

1. Allez sur la page du milestone (ex : Phase 0)
2. Cliquez sur **Close milestone** (bouton en haut à droite)
3. Répétez pour Phase 1, Phase 2, Phase 3

✅ Les milestones fermées apparaîtront avec une coche verte.

## 💡 ASTUCE

GitHub accepte plusieurs formats de date :
- `22/10/2026`
- `2026-10-22`
- `Oct 22, 2026`

Utilisez celui que vous préférez !

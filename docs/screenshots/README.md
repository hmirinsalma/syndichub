# Captures d'écran - SyndicHub

Ce dossier contient toutes les captures d'écran et GIFs de démonstration de l'application SyndicHub.

## 📸 Organisation

### Par acteur
- `admin/` : Captures du tableau de bord administrateur
- `syndic/` : Captures des fonctionnalités syndic
- `resident/` : Captures de l'interface résident

### Par module
- `auth/` : Connexion, réinitialisation de mot de passe
- `residence/` : Gestion des résidences, immeubles, lots
- `payments/` : Appels de fonds, paiements, reçus
- `tickets/` : Création et suivi des tickets
- `announcements/` : Annonces
- `dashboard/` : Tableaux de bord

## 🎬 GIFs de démonstration

Les GIFs de démonstration des parcours utilisateur seront placés dans le dossier `demos/`.

---

**Note** : Les captures d'écran seront ajoutées progressivement au fil du développement.

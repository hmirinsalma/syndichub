# Décisions d'architecture - SyndicHub

Ce dossier contient les notes de décisions d'architecture (ADR - Architecture Decision Records) prises au cours du développement de SyndicHub.

## 📋 Format des ADR

Chaque décision suit le format suivant :

```markdown
# ADR-NNNN : Titre de la décision

**Date** : YYYY-MM-DD
**Statut** : Proposée / Acceptée / Rejetée / Obsolète
**Décideur(s)** : Nom(s)

## Contexte

Description du problème ou de la situation nécessitant une décision.

## Décision

La décision prise et les raisons.

## Conséquences

Les impacts positifs et négatifs de cette décision.

## Alternatives considérées

Les autres options qui ont été envisagées et pourquoi elles n'ont pas été retenues.
```
